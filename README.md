# IALocal - Inteligência Artificial Local no Termux/Android

## 1. Objetivo e Finalidade
Ambiente e scripts de experimentação para execução de modelos de inteligência artificial de forma 100% local em dispositivos móveis Android via Termux.

## 2. Tecnologias Utilizadas
- Shell, Python, Termux, Local LLM

## 3. Arquitetura e Estrutura de Diretórios
Diretório de prototipação focado em scripts leves compatíveis com a arquitetura ARM64 do Android.

## 4. Principais Arquivos e Responsabilidades
- `IDEA.md`: Registro da proposta do projeto (execução de IA local via Termux).
- `.git`: Controle de versões.

## 5. Funcionalidades Identificadas
- Proposta para execução de modelos quantizados em dispositivos portáteis
- Baixo consumo de memória e independência de internet

## 6. Como Compilar ou Executar
Em fase de especificação conforme documentado em `IDEA.md`.

## 7. Estado Atual do Projeto
**Incompleto (Fase de prototipação)**

## 8. Pendências e Limitações Identificadas
Criação dos scripts shell de download de modelos GGUF e binários llama.cpp para Termux.
